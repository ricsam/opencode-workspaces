## What it provides

- Atomic first-user administrator bootstrap.
- Administrator-managed local accounts with Argon2id passwords.
- Runtime-configurable OpenID Connect with discovery, PKCE, verified email, and domain/group policies.
- One root-capable but unprivileged pod per user, with no service-account token or host access.
- On-demand startup, administrator controls, idle scale-to-zero, and retained per-user storage.
- A single authenticated hostname that proxies OpenCode HTTP, streaming, and WebSocket traffic.
- Admin screens for users, workspace status, OIDC, branding, and audit events.

<Note>
  OpenCode Workspaces is a community project. It is not built by or affiliated with the OpenCode team.
</Note>
